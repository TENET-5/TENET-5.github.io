## If you are an AI agent about to edit CSS — read this first

1. Open [`tokens.css`](./tokens.css). Read the §1 banner. Do not skip it.
2. Check [`QUANTANIUM.json`](./QUANTANIUM.json) → `tokens.rules_for_agents`. Those are non-negotiable.
3. **Do not** add a `:root{}` block to any other file. Tokens live in `tokens.css` only.
4. **Do not** invent a new namespace prefix. The canonical prefix is `--slate-*`. Old prefixes (`--bg`, `--text-*`, `--liril-*`, `--font-*`, `--color-*`) are forwarded by the §2 alias layer in `tokens.css` — keep using them in legacy files, but new code references `--slate-*` directly.
5. After editing `tokens.css`, recompute the sha256:
   ```
   python -c "import hashlib,pathlib; print(hashlib.sha256(pathlib.Path('css/tokens.css').read_bytes()).hexdigest())"
   ```
   Update `QUANTANIUM.json` → `canonical_source.sha256` in the **same commit**. The brand guardian rejects drift.

## Why this exists

The site accumulated four conflicting `:root` token namespaces across 17 stylesheets. Every AI session that touched the CSS picked one namespace and "fixed the rest", producing oxblood → red-ensign → monochrome → slate-field-watch oscillations across 310+ pages. Daniel asked for a contract that stops the oscillation: one canonical file, machine-readable, enforced by a guardian, visible to every future agent.

The active palette is **monochrome operational intelligence** (`#202020` base, `#c9a44c` heraldic gold accent, Inter + IBM Plex Mono). Do not migrate without a Daniel-ratified directive and a corresponding update to `QUANTANIUM.json` → `active_palette.id`.

## Cascade load order (fixed)

```
1. /css/tokens.css         ← canonical tokens (THIS DIR)
2. /style.css              ← reset + global primitives
3. /css/<feature>.css      ← feature-specific layers
4. /css/inline_generated.css  ← CI-generated rules (LAST)
```

`tokens.css` must be the **first** stylesheet in every page so its `:root` tokens are available to everything downstream. `inline_generated.css` is generated by the CI pass and goes last so it can ship rule additions but cannot redefine tokens.
