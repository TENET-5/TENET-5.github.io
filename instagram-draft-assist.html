Instagram draft assist

LIRIL drafts captions, hashtags, and alt text for each accountability campaign. You copy. You paste into the Instagram app on your phone. You post.

Manual posting · no automation · no credentials

What this page is. Copy-paste-ready Instagram drafts for the TENET5 accountability campaign. LIRIL reads each campaign in data/grover_target_campaigns.json, drafts the caption via LIRIL, and stores the drafts in data/instagram_drafts.json. This page loads that JSON and renders it.

What this page is not. There is no posting code anywhere in the system. Specifically:

  • No Instagram API client, no browser automation, no clipboard watcher.
  • No credentials are stored, transmitted, or read by any TENET5 system. Credentials pasted into chat must be rotated immediately.
  • You (the human) are the only posting actor. You copy, you open the IG app on your phone, you paste, you hit Share.

Why manual only. The prior Instagram account was hacked (see memory file feedback_no_lirilclaw.md). Automating the recovered account would compound the risk: Instagram's anti-automation detection bans accounts within hours to days for scripted activity. Manual posting with LIRIL-drafted content gets the reach without the ban risk.
